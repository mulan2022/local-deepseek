# 回复收藏（开发版）

点击已结束的 AI 回复下方星标收藏，再点星标取消。侧边栏「收藏」提供列表、
收藏时的原文和可展开的上下文。重新生成的各个回答版本分别标记，不会把
另一个版本也标为满意。回复仍在生成或会话正在压缩时不可收藏。

## 本机记录

实际请求先随回复保存在 IndexedDB 的 requestJournals 和 requestPayloads 表，
收藏时复制到 favorites（列表元数据）和 favoriteSnapshots（独立快照）。
收藏的两个表在同一事务中写入或删除，存储失败不会显示为已收藏。
现有会话数据库升级时不会清空原聊天。

记录包括：

- 来源文件夹 ID、原会话 ID、消息 ID、收藏时间、会话标题、服务商和模型。
  收藏在所有文件夹共享，三元组 ID 避免不同文件夹中的同 ID 回复互相覆盖。
- 收藏时看到的回复文本，以及目标回答的本地原始消息记录。
- 目标回答所属分支从根消息到该回答的完整本地上下文；不包含其他分支或后续轮次。
- 该分支本地已有的记忆注入快照、RCC、思考、用量、压缩及应用事件元数据。
- 上下文附件的元数据和当前本机已有的原件。原件缺失时记录对应 ID，供未来筛选。
- 当轮实际发出的每一次模型请求的完整 JSON：最终的平台格式、系统提示、全部
  messages/input、记忆注入、RCC、摘要、tools 定义、工具结果、图片内容及其他请求参数。
- 同一轮的工具往返、重试和使用同一取消信号的辅助识图模型请求，按发送顺序保存，
  包括时间、HTTP 结果及非鉴权显式请求头。续写追加到该回答的请求记录中。

记录点位于请求完成组装和序列化之后、传输之前，保存实际发送的字符串，不通过
收藏时的最新记忆或工具设置重建。完整请求以 gzip Blob 保存；压缩不可用时保留
原始 JSON Blob，不截断。收藏详情可以展开查看每一次请求的原始 JSON。

修改、继续生成、删除原对话、删除来源文件夹，以及覆盖导入当前文件夹的历史，
都不改动已收藏的快照；取消收藏才会删除它。本机已有附件原件通过独立 Blob 记录保留，
原历史或来源文件夹清理后仍可用。
收藏本身不会写入消息内容、模型提示词或记忆，也不改变后续请求的上下文前缀。
鉴权请求头、Cookie、URL 中的鉴权参数和设置中的 API Key 不写入请求元数据。
用户本身写在聊天内容中的文字按实际请求原样保留。

临时 OCR 截图缓存仍按轮清理，但**已经发给模型的图片会保存在实际请求记录里**，
收藏后即使原缓存清理、原对话删除，仍可保留这部分输入。
未发送的 OCR 图片不因请求留档而保存。收藏本地记录和客户端实际发出的请求，
不能获取服务商内部追加的隐藏提示或服务端处理细节。

旧回复、旧收藏或导入记录没有原始请求时会明确标记为缺失。记录失败、请求内容
未完整落盘或旧回复续写时缺少前段请求，会标记为不完整；不会伪造完整注入。
每次生成有独立的记录身份，避免续写保存失败时把上一段成功记录误当成完整输入。

为支持事后收藏，未收藏的回复也保留实际请求。原对话删除或覆盖导入时清理其
请求留档；已收藏的副本独立保留。本地占用会相应增加。

## 未来训练导出

目前仅保存原始证据与用户的收藏选择，不预设训练 JSON 格式、不自动拼接训练样本。
以后可以按目标模型和任务决定上下文窗口、是否包含系统提示或工具轨迹，
以及如何处理应用事件、思考和附件；不必现在丢弃原上下文。

**收藏与实际请求留档当前仅在本机保存，尚未包含在现有历史 ZIP 导出中。**
导出训练数据和完整备份需要后续实现。

## 验证

运行 pnpm type、pnpm lint、pnpm build。
构建后可运行 node scripts/tests/favorites-browser.mjs dist（默认使用 Windows Edge；
其他 Chromium 浏览器可通过 BROWSER_BIN 环境变量指定）。
实际请求的专项回归：

    node scripts/tests/request-capture-tools.mjs dist
    node scripts/tests/request-capture-providers.mjs dist
    node scripts/tests/request-capture-continuation.mjs dist

浏览器回归测试覆盖旧数据库升级、版本与分支对应、刷新持久化、原历史清空后的
快照与附件保留、取消收藏、存储失败回滚和手机尺寸布局。
同时将收藏中的请求 JSON 与实际发送字符串逐字比对，检查协议转换、记忆、
工具往返、截图、思考签名、多平台与续写记录，不把鉴权信息写入元数据。
测试使用模拟 API，不消耗真实模型用量。

## 返回原对话

收藏列表与详情都有「跳转到原对话」。按来源文件夹、原会话 ID、回答 ID 定位，
必要时先切换文件夹，再短暂高亮目标回答。
如果收藏的是重新生成前的旧回答，会恢复通向该回答的祖先分支，保留其他版本与后续消息。
目标会话正在生成、压缩或导入时提示稍后重试；原对话或消息已删除时保留收藏详情，
明确提示原文不存在，不会将收藏快照冒充为原对话重新导入。

回归测试：node scripts/tests/favorites-browser.mjs dist 与
node scripts/tests/favorite-branches.mjs（Node 24，直接运行 TypeScript 纯分支逻辑）。
